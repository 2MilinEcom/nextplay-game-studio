# NextPlay Game Studio

Local gameplay review workspace with video processing, evidence-linked coaching, and practice tools.

## Technology

Python, JavaScript, Swift, FFmpeg.

## Run locally

Start with `nextplay-studio/README.md`. Install `nextplay-studio/requirements.txt` in a Python virtual environment; video processing also requires FFmpeg. Personal gameplay recordings, player profiles, reports, local settings, and the large recognition model are excluded. Recognition features require obtaining the model described in `nextplay-studio/models/units-manifest.json` and its license. This source snapshot does not bundle the compiled macOS player application.

## Portfolio snapshot

This repository contains a source snapshot of a personal project. Personal records, credentials, browser sessions, local databases, and generated output are excluded. Use your own configuration and fictional data when evaluating it. Some integrations require external accounts or additional setup. This is a development project, with feature limitations documented in the source and guides.
